- Grouped navigation: Command, Air Operations, Force Management, Engineering, C-UAS, and System.
- Route-aware nested back stack that restores the precise workspace.
- Correct RTL shell mirroring, right-side navigation, Arabic alignment, and Noto Kufi Arabic preference.
- Ten-locale smoke coverage: AR, EN, TR, ES, DE, IT, FR, UR, FA, RU.
- Map-first Command Overview with readiness, bases, sustainment, training, provider status, and incident summary.

- Aircraft technical storyboard for jet, turboprop, helicopter, and UAV with top/side silhouettes, system overlay, Digital Twin, diagnostics, readiness, and maintenance state. Silhouettes are generated in QML Canvas; no external image asset or license is required.

- Runtime gates for every page/workspace, navigation restoration, RTL, and ten languages.
