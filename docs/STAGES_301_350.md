## UI behavior

- MFD, Systems and Alerts navigation buttons are wired to real pages.
- Arabic changes layout mirroring to RTL and translates cockpit chrome and instrument labels.
- Scenario selection resets and restarts the deterministic training simulation.
- The UI consumes only `CockpitViewModel` / `LabSnapshot` data rather than reaching into simulation internals.

## Scope

This remains a synthetic training/reliability HMI. It has no targeting, weapon-control, guidance, firing, or live-aircraft control interfaces.
