# NEXVARY Avionics Lab — Stage Ledger 351–400

This release train strengthens verification and reproducibility for synthetic training telemetry. It does not add live-aircraft connectivity, targeting, guidance, weapon control, or combat automation.

| Stages | Gate | Delivered capability |
|---|---|---|
| 351–360 | Archive format | Versioned `NEXVARY_TELEMETRY_V1` deterministic text archive for synthetic telemetry frames |
| 361–370 | Round-trip fidelity | Full double-precision serialization, stable sensor ordering and encode/decode equality verification |
| 371–380 | Integrity summary | Frame/sample counts, invalid-sample count, sequence monotonicity and simulation-time monotonicity |
| 381–390 | Verification fingerprint | FNV-1a 64-bit deterministic archive checksum plus Markdown verification report |
| 391–400 | Defensive release gate | Malformed-header/footer/record guards, duplicate-sensor rejection and dedicated cross-platform `archive_tests` |

## Stage 400 exit criteria

- Existing core/HMI tests remain green.
- `archive_tests` passes on supported CI platforms.
- Encoding a decoded archive reproduces the original archive byte-for-byte for supported synthetic data.
- Corrupt/unsupported headers are rejected rather than silently accepted.
- Non-monotonic frame sequences are observable in the verification summary.
- Verification reports explicitly identify the data as synthetic training telemetry with no live-aircraft interface.
