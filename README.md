# NEXVARY Avionics Lab

Windows-first avionics training and simulation platform with synthetic telemetry, health monitoring, replay, trend analysis, fault-lab workflows, digital-twin views, and engineering verification surfaces.

Current product line: **v2.3.0 / Stage 1250+**.

The project is strictly training/simulation software. It does not provide live-aircraft control, targeting, weapon-control, guidance, firing, or combat automation.
