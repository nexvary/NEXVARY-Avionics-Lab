# Stages 1251–1300 — Simulation Provider API

| Stages | Gate | Deliverable |
|---|---|---|
| 1251–1260 | Provider contract | Abstract reset/scenario/step lifecycle |
| 1261–1270 | Native adapter | Existing deterministic ScenarioEngine wrapped as NativeSyntheticProvider |
| 1271–1280 | Lab decoupling | AvionicsLab consumes SimulationProvider instead of ScenarioEngine directly |
| 1281–1290 | Provider identity | Runtime provider id is explicit and testable |
| 1291–1300 | Verification | Provider contract and dropout behavior covered by CTest |

The API is intentionally simulation-only. Future external physics engines must implement this boundary and cannot bypass SensorBus, Health, Recorder or EventLog.
