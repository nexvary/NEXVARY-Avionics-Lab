# Stage Ledger 701–750 — Cockpit Trend Console

This milestone exposes synthetic telemetry trend intelligence inside the Qt/QML training HMI. It does not add live-aircraft connectivity, targeting, guidance, weapon control, or combat automation.

| Stages | Gate | Delivered capability |
|---|---|---|
| 701–710 | Bridge integration | `CockpitBridge` exposes reusable `trendRows` from `TelemetryTrendAnalyzer` |
| 711–718 | Rolling controls | HMI can select 20, 60, 120 or all recorded frames |
| 719–728 | Data-quality display | Validity quality percentage includes invalid and missing samples |
| 729–738 | Trend console | Latest, mean, min, max, delta and slope/s displayed per sensor |
| 739–744 | Localization | Trend page labels support English and Arabic RTL |
| 745–748 | Navigation gate | Trends is a first-class page with working Back navigation |
| 749–750 | Qt verification | `qt_bridge_tests` plus headless QML smoke validate the integration |

## Stage 750 exit criteria

- Stage 700 core and report tests remain green.
- `qt_bridge_tests` verifies window changes and sensor-dropout quality degradation.
- QML loads headlessly with the Trends page present.
- Arabic remains RTL and trend labels are translated.
- Trend calculations continue to use recorded synthetic simulation frames only.
