# Stages 1201–1250 — Windows Product Identity Gate

This gate removes release-version drift and makes the Windows deliverable self-consistent.

| Stages | Gate | Deliverable |
|---|---|---|
| 1201–1210 | Build identity | One source-of-truth header for product, version, stage and channel |
| 1211–1220 | CLI identity | Runtime version output consumes the shared build identity |
| 1221–1230 | Installer identity | Inno Setup moves to version 2.3.0 |
| 1231–1240 | Artifact naming | Windows CI artifact identifies Stage 1250 / v2.3.0 instead of Stage 1100 |
| 1241–1250 | Verification | Release-identity unit test joins the portable CTest suite |

All functionality remains training/simulation only. No live-aircraft or weapon-control path is introduced.
