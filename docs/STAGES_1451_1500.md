# Stages 1451–1500 — Unified Time & History Model

| Stages | Gate | Deliverable |
|---|---|---|
| 1451–1460 | Timeline frame index | Sequence and simulation-time points from recorded telemetry |
| 1461–1470 | Event index | Event ordering represented as wall-clock offsets from the first event |
| 1471–1480 | Time navigation | Nearest recorded frame lookup for arbitrary simulation time |
| 1481–1490 | Event windows | Inclusive event-window filtering with reversed-range normalization |
| 1491–1500 | Verification | Timeline duration, seek and event-window behavior covered by CTest |

The model deliberately keeps simulation time and event wall-time offsets explicit instead of pretending they are the same clock.
