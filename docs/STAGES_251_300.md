# Stage Ledger 251–300 — Cockpit Data Layer

These stages move the verified simulation core toward a graphical training cockpit without coupling safety/reliability logic to a GUI framework.

| Stages | Gate | Capability |
|---|---|---|
| 251–260 | HMI boundary | GUI-independent cockpit view-model namespace and DTOs |
| 261–270 | Instrument tiles | Altitude, airspeed, attitude, power, compute, hydraulic, fuel presentation |
| 271–280 | Annunciator model | Active alerts mapped to cockpit warning text |
| 281–290 | Degraded data | Missing/invalid sensor states become explicit FAULT tiles |
| 291–300 | HMI verification | Cross-platform unit test integrated into CMake/CTest |

## Design decision

Qt/QML will be an optional presentation adapter in a later gate. The Stage 300 view model remains standard C++20, so the simulation and verification suite does not require a GUI installation and remains deterministic in CI.

## Safety scope

The HMI displays synthetic training telemetry and system-health information only. It contains no targeting, weapon-control, guidance, firing, or live-aircraft control interfaces.
