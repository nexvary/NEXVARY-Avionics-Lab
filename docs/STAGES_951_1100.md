# Stages 951–1100 — Aerospace Professionalization

This gate deliberately changes presentation architecture without changing the verified simulation core.

| Stages | Gate | Deliverable |
|---|---|---|
| 951–975 | Industrial design system | Flatter graphite/navy surfaces, restrained gold, technical typography, tighter density |
| 976–1000 | Executive mode | Dense readiness strip, digital-twin overview, PFD/MFD, events and live performance |
| 1001–1025 | Engineering mode | System synoptic and telemetry workbench with multi-channel plots and cursor |
| 1026–1050 | Diagnostic mode | Runtime Verification Center with evidence-backed live checks |
| 1051–1075 | Navigation model | Explicit Executive / Engineering / Diagnostic work modes plus direct page navigation |
| 1076–1100 | Release gate | Windows/Linux/ASan/UBSan/Qt smoke, expanded visual captures and Windows installer |

## Design rules

- No oversized consumer-style cards or decorative gauges without data provenance.
- State colors remain semantic: green nominal, amber degraded/attention, red fault, cyan engineering data.
- Gold is a restrained identity accent, not the primary information color.
- Engineering and diagnostic surfaces prioritize density, alignment, evidence and traceability.
- Arabic RTL and English LTR remain first-class modes.
- Runtime Verification Center is explicitly training/runtime assurance evidence, not certification.
- No live-aircraft control, targeting, guidance, weapons or firing interfaces are introduced.

## Stage 1100 exit criteria

1. All legacy core tests remain unchanged and green.
2. Qt/QML builds and smoke tests on Linux.
3. Visual gate captures Executive, Engineering and Diagnostic surfaces.
4. Windows MSVC Qt build succeeds and `windeployqt` completes.
5. One-click Windows installer and portable package are generated.
