# Stage Ledger 901–950 — Windows Productization & Instrument Hardening

This milestone turns the Stage 900 ministerial cockpit into a Windows-first distributable application while improving the primary-flight and telemetry visual layers. The simulation scope remains software-only and training-focused.

| Stages | Gate | Delivered capability |
|---|---|---|
| 901–910 | MFD tape instruments | Dedicated altitude and airspeed tapes with live synthetic values |
| 911–920 | Attitude hardening | Roll scale, pitch ladder, aircraft reference mark and smooth transitions |
| 921–928 | Telemetry chart hardening | Grid-backed sparklines with live endpoint marker and resize-safe repaint |
| 929–936 | Windows Qt build | Dedicated MSVC 2022 + Qt 6 package workflow |
| 937–942 | Runtime deployment | `windeployqt` collects Qt/QML runtime dependencies automatically |
| 943–946 | Portable distribution | CI emits a self-contained Windows portable ZIP |
| 947–950 | One-click installer | Inno Setup emits `NEXVARY-Avionics-Lab-Setup.exe` and uploads it as a release artifact |

## Stage 950 exit criteria

- Core Windows/Linux and sanitizer gates remain unchanged.
- Qt/QML ministerial screenshot gate remains available.
- Windows Qt bridge tests pass before packaging.
- The packaged executable contains the required Qt runtime deployment.
- A portable ZIP is produced without requiring CMake on the end-user machine.
- A one-click `NEXVARY-Avionics-Lab-Setup.exe` artifact is produced by CI.
- No targeting, weapon-control, guidance, firing or live-aircraft control functions are introduced.
