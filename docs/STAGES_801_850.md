# Stage Ledger 801–850 — Synthetic Fault Lab

This milestone adds a bounded, software-only fault console for training and verification. Presets act only on the synthetic SensorBus; no live-aircraft or hardware-control path is introduced.

| Stages | Gate | Delivered capability |
|---|---|---|
| 801–810 | Fault isolation | Scenario faults and operator-selected training faults use separate injectors |
| 811–820 | Preset catalog | Three bounded presets: IMU dropout, low power bus, compute over-temperature |
| 821–830 | Audit trail | Apply, clear and rejected-preset actions enter EventLog |
| 831–838 | Recovery semantics | Clear and Reset restore nominal synthetic sensor generation |
| 839–844 | HMI bridge | Preset list, active-fault rows and active count exposed to Qt/QML |
| 845–848 | Localization | English/Arabic labels and explanatory safety notice |
| 849–850 | Release gate | Dedicated fault-console test, Qt bridge test, headless QML and existing CI gates |

## Architectural rule

The HMI cannot submit arbitrary sensor names or arbitrary values. It can only request presets defined in `TrainingFaultCatalog`, keeping the training surface deterministic, auditable and testable.
