# Stage Ledger 651–700 — Telemetry Trend Intelligence

This milestone extends synthetic training telemetry analysis. It does not add live-aircraft connectivity, targeting, guidance, weapon control, or combat automation.

| Stages | Gate | Delivered capability |
|---|---|---|
| 651–660 | Shared trend core | `TelemetryTrendAnalyzer` becomes the single reusable statistics engine |
| 661–670 | Data quality | Valid, invalid and missing-sample accounting per sensor |
| 671–680 | Time behavior | Latest value, delta and per-second slope across valid samples |
| 681–688 | Rolling window | Optional latest-N-frame trend analysis for focused QA |
| 689–694 | Reporting v2 | JSON/Markdown reports include trend and data-quality fields |
| 695–698 | CLI control | `--trend-window` controls report analysis without changing the recorded session |
| 699–700 | Verification gate | Dedicated `trends_tests` plus existing Windows/Linux/sanitizer/Qt gates |

## Stage 700 exit criteria

- Existing tests remain green.
- `trends_tests` covers nominal, dropout, missing and invalid data.
- Statistics are deterministic for the same recorded frames.
- Trend slope uses simulation time rather than wall-clock time.
- Report schema is versioned as `nexvary-avionics-verification/v2`.
- The milestone remains explicitly synthetic training/simulation software only.
