# Stages 1601–1650 — Release Manifest & Dependency Governance

| Stages | Gate | Deliverable |
|---|---|---|
| 1601–1610 | Dependency records | Name, version, license, role, source and optional/runtime status |
| 1611–1620 | Core inventory | nlohmann-json and CLI11 pinned and declared |
| 1621–1630 | UI/package inventory | Qt and Inno Setup recorded separately from core dependencies |
| 1631–1640 | Machine-readable manifest | Versioned JSON release-manifest schema with product/stage/scope metadata |
| 1641–1650 | Verification | Manifest parses and every dependency has license/source evidence |

The manifest is an engineering inventory, not legal advice. New third-party code must pass license/provenance review before entering a release.
